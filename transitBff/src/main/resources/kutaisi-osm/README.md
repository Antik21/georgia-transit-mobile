See [OpenStreetMap copyright and attribution](https://www.openstreetmap.org/copyright).

The file contains the selected bus-stop nodes inside OSM municipality
[2024547](https://www.openstreetmap.org/relation/2024547). It records the source replication
timestamp and SHA-256 of the input [Geofabrik Georgia extract](https://download.geofabrik.de/europe/georgia.html).
The import command and data review are in [the Kutaisi integration notes](../../../../../docs/development/kutaisi-integration.md).
